분기를 실행해 검증했다는 의미는 아닙니다.

- 미작성·중복·알 수 없는 항목, 원문 해시, 변수·태그·수치·능력치 효과를 검사했습니다.

- 이름·조직·왕국 표기 36곳을 통일했습니다. 변경 범위는 서로 겹칩니다.
- 186개 숫자 경고를 원문과 대조했습니다. 영문 철자→숫자, October→10월 같은 정상

- 이미지 UI·매뉴얼 49종(실제 텍스처 51개, 에셋 파일 6개)의 픽셀이 최종 PNG와 일치합니다.
- 브리지 0.1.4 빌드: 경고·오류 0. 계약 검사 및 설치·복구 테스트 12개 통과.
- 사용자 제보의 영어 능력치 이름을 수정했습니다. `AwakeMe` 두 경로의 IL 연결 위치와

## 폰트

감자꽃은 현재 번역에서 사용하는 한글 1,428종을 전부 지원합니다. 주아에는 `쎔·웻·큥`이
없습니다. 기존 브리지는 전체 한글 범위를 만족하지 못한 제목 글꼴을 Windows 맑은 고딕으로
대체합니다. 새 글꼴이나 빗썸 고딕은 이번 패키지에 추가하지 않았습니다.
악센트가 있는 크레딧 인명과 일부 비한글 기호는 원본 글꼴에 없으므로 실제 화면에서
확인해야 합니다. 전체 글리프 시각 검증을 통과한 상태는 아닙니다.

## 복사·덮어쓰기 패키지

3편과 같은 방식은 `build/releases/Monster-Con-KR-test-QA2-Windows-DragDrop.zip`입니다.
ZIP 내용물을 `MonsterCon.exe`가 있는 폴더에 복사하고 같은 파일을 덮어쓰면 됩니다.
별도 설치 프로그램·Python·명령은 필요 없습니다. 텍스트와 이미지·매뉴얼이 모두 포함됩니다.
56개 ZIP 항목의 SHA256을 대조했고 약 130 MB입니다.
[상세 적용 안내](DRAGDROP_INSTALL_KO.txt). 자동 백업은 만들지 않으며 옛 설치 기록은 갱신하지 않습니다.

아래 스크립트 설치 방식도 유지합니다.

## 로컬 패키지

`build/releases/MonsterCon-KR-test-20261026-QA2/`에 텍스트·브리지·폰트·이미지·매뉴얼을
함께 넣었습니다. 49개 파일, 약 321 MB입니다. 게임 에셋을 포함한 로컬 테스트 산출물이며
Git에는 올리지 않습니다. 이 작업에서 실제 게임 설치나 실행은 하지 않았습니다.

패키지 폴더에서 아래 명령을 사용합니다. Python 3가 필요하며 추가 Python 패키지는
설치기에 필요하지 않습니다. 다른 설치 경로는 `--game "설치 경로"`를 덧붙입니다.
기본 경로라면 `Check.cmd`, `Install.cmd`, `Restore.cmd`를 실행해도 같습니다.

```powershell
python -X utf8 manage_patch.py check
python -X utf8 manage_patch.py install
python -X utf8 manage_patch.py restore
```

`check`는 게임을 바꾸지 않습니다. 현재 개발 PC에서 모든 49개 파일의 사전 검사를
통과했습니다. `install`은 게임이 종료된 경우에만 동작하고 알려진 이전 미리보기 파일만
갱신합니다. 이미 같은 이미지 패치가 설치되어 있으면 해당 파일을 다시 쓰지 않습니다.
변경 전 파일은 게임 폴더 `.monstercon-kr-test` 아래에 백업합니다.

`restore`는 **이 패키지를 설치하기 직전 상태**로 되돌립니다. 이전 미리보기·이미지
한패가 이미 설치되어 있었다면 그대로 남습니다. 설치 뒤 다른 도구가 바꾼 파일은
덮어쓰지 않습니다. 예전 저장소의 제거 도구는 이번 패키지를 복구한 다음에 사용하세요.

## 사용자 화면 테스트

영어 언어 슬롯에서 시작하고 메뉴, 프롤로그, 일반 이벤트, 만화·상점·데이트·엔딩,
저장·로드를 확인합니다. 이미지 UI와 설정의 매뉴얼도 함께 확인합니다.

글자 잘림 후보 37개는 `TEXT_QA_REPORT.json`의 `long_strings_for_user_screen_test`에
기록했습니다. 길이만으로 오류를 판정하지 않았으며, 크레딧처럼 원래 긴 항목도 포함됩니다.
화면 문제는 화면 이름/대사/이벤트 또는 매뉴얼 페이지 번호로 추적할 수 있습니다.

검사를 다시 실행하려면:

```powershell
python -X utf8 scripts/build_playtest.py
python -X utf8 scripts/build_ui_preview.py
python -X utf8 scripts/audit_translation.py
python -X utf8 scripts/audit_images.py
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts/package_playtest.py
```

전체 문장 교열, 실제 글꼴·레이아웃, 모든 분기 회귀 검증은 남아 있습니다.
