# 몬스터 프롬 4: 몬스터 콘 한국어 패치 v0.2.0

**대상:** Steam Windows x86 · 게임 빌드 **26248979** (2026-10-27 업데이트).

## 수정 사항
- v0.1.0 패치 설치 시 시작 로딩 도중 `sharedassets2.assets is corrupted` 오류와 함께 게임이 종료되는 문제를 수정했습니다.
- 게임 업데이트로 직렬화 구조가 달라진 Unity 에셋 6개를 **최신 원본 게임 파일을 기준으로 다시 빌드**했습니다.
- 기존 한국어 이미지 49종(게임 설명서 및 UI), 번역 텍스트 24,274개, 글꼴 2종, 한글 이름 저장 보호를 유지했습니다.
- **게임 `Assembly-CSharp.dll`은 배포하지 않습니다.** 업데이트 이후 DLL 해시가 달라졌지만 한국어 브리지 0.1.7의 Harmony 후킹을 새 게임에서 확인했으므로 기존 브리지 DLL은 유지합니다.

## 설치
1. 게임을 종료합니다.
2. 이전 v0.1.0 설치자라면 **Steam → 속성 → 설치된 파일 → 게임 파일 무결성 검사**로 구버전 에셋 파일을 원상 복구하는 것을 권장합니다.
3. 릴리스 ZIP인 `Monster-Con-KR-v0.2.0-Windows-DragDrop.zip`을 풉니다.
4. 압축 속 `BepInEx`, `MonsterCon_Data`, `winhttp.dll` 등을 **`MonsterCon.exe`가 있는 폴더**에 복사해 덮어씁니다.
5. **Steam에서 실행**하고 영어 언어 슬롯을 사용합니다.

기존 세이브·설정은 ZIP에 포함하지 않았으며 자동 백업은 만들지 않습니다. 다른 게임 빌드에서는 이 패치를 그대로 적용하지 마세요.

## 검증
- 문제 재현: 구버전 v0.1.0을 최신 게임에 설치한 복제본에서 오프닝 이후 `sharedassets2.assets is corrupted` → Unity 충돌.
- 수정: 업데이트된 게임 에셋 6개에 한국어 이미지 49종을 다시 적용. Unity 오브젝트 ID/대상 외 데이터 보존, 텍스처 픽셀 일치 확인.
- 수정된 통합 패치로 오프닝 → **타이틀 장면** 진입 및 **152초 실행**, 로딩 충돌·Unity 직렬화 오류 0건.
- BepInEx 5.4.23.2 및 한국어 브리지 0.1.7의 후킹, 글꼴, 번역 텍스트 로딩 확인.

**아직 검증하지 않은 범위:** 새 게임 시작 이후 모든 분기, 실제 저장/불러오기, 모든 UI/이미지 화면. 타이틀 화면까지의 충돌 수정 확인이지 전체 게임의 무오류 보증은 아닙니다.
