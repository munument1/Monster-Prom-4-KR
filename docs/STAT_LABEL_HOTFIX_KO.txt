몬스터 프롬 4: 몬스터 콘 — 능력치 이름 표시 수정 0.1.6

기존 통합 한글 패치를 적용한 상태에서 사용하는 작은 수정 패치입니다.
게임을 종료하고 이 ZIP의 내용물을 MonsterCon.exe가 있는 폴더에 복사하여 덮어쓰세요.
교체 파일: BepInEx\plugins\MonsterConKoreanBridge\MonsterConKoreanBridge.dll

SMARTS → 지능
BOLDNESS → 대담함
CREATIVITY → 창의력
CHARM → 매력
FUN → 재미
MONEY → 돈

능력치 창과 대화 속 증감 표기가 내부 영문 이름을 직접 표시하던 부분을 수정했습니다.
대화의 +2 CREATIVITY는 +2 창의력으로, -2 SMARTS는 -2 지능으로 표시됩니다.
게임이 능력치 증감을 해석한 뒤 표시용 이름만 바꾸므로 부호·수치·색상은 유지됩니다.
표시 이름을 바꾼 다음 애니메이션용 보조 라벨을 만들도록 연결합니다.
이벤트 코드·능력치 수치·세이브 데이터는 변경하지 않습니다.
전체 UI 주기 검색을 추가하지 않았으며 글자 출력 때마다 번역 검색을 하지 않습니다.

이 ZIP은 DLL만 교체하므로 이전 통합 패치의 텍스트·폰트·로더·이미지가 필요합니다.
게임 실행 테스트는 사용자가 진행합니다.

0.1.6은 일시정지 창과 내부 이름의 대소문자 차이도 처리합니다.
나레이터 반말 교정까지 적용하려면 별도의 나레이터·스탯 통합 수정 ZIP을 사용하세요.
