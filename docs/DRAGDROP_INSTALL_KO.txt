몬스터 프롬 4: 몬스터 콘 — 덮어쓰기 방식 통합 테스트 패치

적용 방법
1. 게임을 종료합니다.
2. ZIP 안의 내용물을 MonsterCon.exe가 있는 게임 폴더에 복사합니다.
   기본 경로: C:\Games\Steam\steamapps\common\Monster Prom 4 - Monster Con
3. 같은 이름의 파일은 모두 덮어씁니다.
4. Steam에서 게임을 실행합니다. 언어는 영어 슬롯을 사용합니다.

별도 설치 프로그램, Python, 명령 실행은 필요 없습니다.
ZIP 안에 BepInEx, MonsterCon_Data, winhttp.dll 등이 바로 보이는 구성이 맞습니다.
패키지 폴더 자체를 게임 폴더 안에 넣는 것이 아니라 그 안의 내용물을 복사하세요.
현재 PC의 이전 텍스트 미리보기·이미지 한패 위에도 같은 방식으로 덮어쓸 수 있습니다.

포함 내용
- 추출된 텍스트 23,986개 번역
- 이미지 UI·매뉴얼 49종
- 브리지 0.1.5(능력치 창·대화 속 능력치 이름 한글 표시 수정), 로더 및 한글 폰트

이 방식은 자동 백업을 만들지 않습니다. 되돌릴 때를 위해 기존 파일을 보관하려면
복사 전에 ZIP의 MONSTERCON_KR_MANIFEST.json에 있는 대상 파일을 따로 백업하세요.
기존 스크립트 설치 기록은 갱신되지 않으므로, 덮어쓴 뒤에는 옛 제거 도구가 해시 불일치로
중단될 수 있습니다. 이 ZIP에는 별도 자동 제거 도구를 넣지 않았습니다.

원본 게임 에셋 복구는 Steam 파일 무결성 검사로 할 수 있지만, 추가된 번역 TXT·로더·
플러그인은 Steam 검사만으로 삭제되지 않습니다. 해당 추가 파일도 제거해야 합니다.
다른 한패나 모드가 함께 있다면 그 파일을 구분해 보관하세요.

대상: Windows x86 / Steam build 26157563.
이 패키지에는 교체용 게임 에셋이 포함되어 있으며 로컬 테스트용입니다.
정적 검사와 주요 언어 문제 교정을 마쳤으며 전체 문장 교열·화면·모든 분기 검증은 남아 있습니다.
게임 실행 테스트는 사용자가 진행합니다. 패키지 제작 과정에서는 게임을 실행하거나 수정하지 않았습니다.
