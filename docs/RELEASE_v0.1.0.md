Windows판 첫 한국어 패치입니다. 사용자의 인게임 플레이 확인을 거친 통합본입니다.

- 현재 추출한 텍스트 24,274개 번역
- 이미지 UI·게임 매뉴얼 49종
- 능력치 창·대화·일시정지 창의 능력치 이름 한글 표시
- 나레이터 말투 교정 및 만화 선택지 288개 항목 추가
- 한글 이름 저장·불러오기 보호 포함, 브리지 0.1.7

## 적용

릴리즈에서 **Monster-Con-KR-v0.1.0-Windows-DragDrop.zip**을 받으세요.
GitHub의 자동 생성 `Source code` 파일은 게임에 바로 적용하는 패키지가 아닙니다.

1. 게임을 종료합니다.
2. ZIP 안의 내용물을 **MonsterCon.exe가 있는 폴더**에 복사합니다.
3. 같은 파일은 덮어씁니다.
4. Steam에서 실행하고 **영어 언어 슬롯**을 사용합니다.

기본 설치 경로는 `C:\Games\Steam\steamapps\common\Monster Prom 4 - Monster Con`입니다.
ZIP 안의 `BepInEx`, `MonsterCon_Data`, `winhttp.dll`이 게임 폴더에 바로 들어가면 됩니다.
별도 설치 프로그램이나 Python은 필요 없습니다.

대상은 Windows x86 / Steam build **26157563**입니다. 덮어쓰기 방식은 자동 백업을 만들지 않습니다.
개인 세이브·설정·로컬 백업은 배포 ZIP에 포함하지 않았습니다.
